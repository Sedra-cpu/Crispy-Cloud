
# ☁️ Crispy Cloud - Landing Page & UI Concept

> Note:This project is a **Concept / Portfolio Prototype** developed for a freeze-dried fruit business idea (crispy fruit snacks). The business is currently inactive/unreleased, and this repository serves as a frontend UI/UX demonstration.

 🍓 Overview
Crispy Cloud is a modern, responsive landing page designed to showcase natural freeze-dried fruit snacks. It features an interactive product catalog, a slide-out cart drawer with dynamic item updates, and a clean, food-centric layout.
